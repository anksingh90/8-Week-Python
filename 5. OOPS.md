OOPs In Python

1. Class & Object

Def : A Class is a user-defined template or blueprint used to create objects. It bundles methods & data into single logical unit.

Lets understand this with example - 

```python
class Car:                              # name of class is in capitalize
    # __init__ is a method which gets executed once class Car gets initialized via object.
    def __init__(self, brand, model):   # self is a method which handles the object data for entire execution
        self.brand = brand              # to access value of object obj, we need to initilize using self
        self.model = model

obj = Car("Tata", "Tiago")              # object of class Car created with passing brand & model
print(obj.brand())                      # accessing obj brand value : Output - Tata

```

We can use multiple objects with fresh value and have these details stored in DB.

2. Class Method & Self Function  

Creating first function within the class.

```python
class Car:
    def __init__(self, brand, model):   
        self.brand = brand              
        self.model = model
    
    # creating a new function which returns name of car.
    def car_name(self):
        return f"The name of Model is : {self.model}"

obj = Car("Tata", "Tiago")
print(obj.car_name())       # to access method within class, we need to call it via object of class followed by method name.

```

3. Inheritance

We will create a new class - ElectricCar that will inherit properties from class Car along with additional attributes.

```python
class Car:
    def __init__(self, brand, model):   
        self.brand = brand              
        self.model = model
    
    def car_name(self):
        return f"The name of Model is : {self.model}"
    
class ElectricCar(Car):         # Declaration syntax : class Class_name(Name_of_Class_Inheriting)
    def __init__(self, brand, model, battery_size):     # initializing all the variables.
        super().__init__(brand, model)                  # using keywork super(), we are accessing brand, model from Car class.
        self.battery_size = battery_size

obj = Car("Tata", "Tiago")
print(obj.car_name())

e_obj = ElectricCar("Tata",'E-Tiago','50kWh')
print(e_obj.model)
print(e_obj.car_name())

```

4. Encapsulation

Def : Enclosing/Hiding data from outer world.

Task : Modify class Car to encapsulate the brand attribute, making it private.

```python
class Car:
    def __init__(self, brand, model):   
        self.__brand = brand            # declaring brand as private attribute          
        self.model = model

    # to declare a private variable, we need to use get_name_of_attribute
    def get_brand(self):
        return self.__brand             # returing private attribute
    
    def car_name(self):
        return f"The name of Model is : {self.model}"


obj = Car("Tata", "Tiago")
print(obj.car_name())
print(obj.get_brand())

```
