OOPs In Python

1. Class & Object

Def : A Class is a user-defined template or blueprint used to create objects. It bundles methods & data into single logical unit.

Lets understand this with example - 

```python
class Car:                              # name of class is in capitalize
    # __init__ is a method which gets executed once class Car gets initialized via object.
    def __init__(self, brand, model):   # self is a method which handles the object data for entire execution
        self.brand = brand              # to access value of object obj, we need to initilize using self
        self.model = model

obj = Car("Tata", "Tiago")              # object of class Car created with passing brand & model
print(obj.brand())                      # accessing obj brand value : Output - Tata

```

We can use multiple objects with fresh value and have these details stored in DB.

2. Class Method & Self Function  

Creating first function within the class.

```python
class Car:
    def __init__(self, brand, model):   
        self.brand = brand              
        self.model = model
    
    # creating a new function which returns name of car.
    def car_name(self):
        return f"The name of Model is : {self.model}"

obj = Car("Tata", "Tiago")
print(obj.car_name())       # to access method within class, we need to call it via object of class followed by method name.

```
