## 1. Class & Object

**Definition:** A class is a user-defined template or blueprint used to create objects. It bundles data and behavior (methods) into a single logical unit.

```python
class Car:                              # class names are capitalized (PascalCase)
    def __init__(self, brand, model):   # __init__ runs automatically when an object is created
        self.brand = brand              # self binds data to the specific object being created
        self.model = model

obj = Car("Tata", "Tiago")              # creating an object of class Car
print(obj.brand)                        # Output: Tata
```

> **Note:** `obj.brand` is an attribute, not a method — no parentheses needed to access it.

You can create multiple objects, each holding its own independent set of values (e.g., before saving them to a database).

## 2. Class Methods & `self`

Methods are functions defined inside a class that operate on an object's data.

```python
class Car:
    def __init__(self, brand, model):
        self.brand = brand
        self.model = model

    def car_name(self):                 # a custom method
        return f"The name of the model is: {self.model}"

obj = Car("Tata", "Tiago")
print(obj.car_name())                   # call methods via the object, using dot notation
```

## 3. Inheritance

Inheritance lets one class (the **child**) reuse and extend the attributes and methods of another (the **parent**).

Here, `ElectricCar` inherits from `Car` and adds a new attribute.

```python
class Car:
    def __init__(self, brand, model):
        self.brand = brand
        self.model = model

    def car_name(self):
        return f"The name of the model is: {self.model}"


class ElectricCar(Car):                         # syntax: class Child(Parent)
    def __init__(self, brand, model, battery_size):
        super().__init__(brand, model)          # super() calls the parent's __init__
        self.battery_size = battery_size


obj = Car("Tata", "Tiago")
print(obj.car_name())

e_obj = ElectricCar("Tata", "E-Tiago", "50kWh")
print(e_obj.model)
print(e_obj.car_name())
```

## 4. Encapsulation

**Definition:** Restricting direct access to an object's internal data, exposing it only through controlled methods.

```python
class Car:
    def __init__(self, brand, model):
        self.__brand = brand            # double underscore prefix makes this "private"
        self.model = model

    def get_brand(self):                # public getter method for the private attribute
        return self.__brand

    def car_name(self):
        return f"The name of the model is: {self.model}"


obj = Car("Tata", "Tiago")
print(obj.brand)                        # AttributeError: 'Car' object has no attribute 'brand'
print(obj.get_brand())                  # Output: Tata
```

> **Convention:** Private attributes are accessed via `get_`/`set_` style methods rather than directly.

## 5. Polymorphism

**Definition:** The ability of different objects to respond to the same interface (method call) in their own way.

```python
class CreditCard:
    def process_payment(self, amount):
        return f"Charging ${amount} to Credit Card"

class Paytm:
    def process_payment(self, amount):
        return f"Redirecting ${amount} to Paytm gateway"

# Works with any object that has a process_payment method
def complete_checkout(payment_gateway, amount):
    print(payment_gateway.process_payment(amount))

complete_checkout(CreditCard(), 100)    # Output: Charging $100 to Credit Card
complete_checkout(Paytm(), 50)          # Output: Redirecting $50 to Paytm gateway
```

## 6. Class Variables

Also called **static variables**. A class variable is defined directly inside the class body (outside any method) and is shared by **all** instances of that class — it exists in only one place in memory.

**Real-world use:** Storing data that should be common to every object of a class (e.g., a company name, a school name, a tax rate).

```python
class Student:
    school_name = "Bloom School"        # class variable — shared by all students

    def __init__(self, name):
        self.name = name                # instance variable — unique per student

# Accessing via the class name (recommended)
print(Student.school_name)              # Output: Bloom School

stu1 = Student("Ami")
stu2 = Student("Amy")

print(stu1.school_name)                 # Output: Bloom School
print(stu1.name)                        # Output: Ami
print(stu2.school_name)                 # Output: Bloom School
print(stu2.name)                        # Output: Amy
```

## Quick Summary

| Concept | Core Idea |
|---|---|
| **Class & Object** | Blueprint vs. actual instance |
| **`self`** | Refers to the current object instance |
| **Inheritance** | Reuse parent class behavior in a child class |
| **Encapsulation** | Hide internal data, expose via methods |
| **Polymorphism** | Same method name, different behavior per class |
| **Class Variable** | Shared value across all instances |
