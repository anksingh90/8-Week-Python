1. Class & Object

Def : A Class is a user-defined template or blueprint used to create objects. It bundles methods & data into single logical unit.

Lets understand this with example - 

```python
class Car:                              # name of class is in capitalize
    # __init__ is a method which gets executed once class Car gets initialized via object.
    def __init__(self, brand, model):   # self is a method which handles the object data for entire execution
        self.brand = brand              # to access value of object obj, we need to initilize using self
        self.model = model

obj = Car("Tata", "Tiago")              # object of class Car created with passing brand & model
print(obj.brand())                      # accessing obj brand value : Output - Tata

```

We will create a new class - ElectricCar that will inherit properties from class Car along with additional attributes.

```python

    def __init__(self, brand, model):   
        self.brand = brand              
        self.model = model
```

5. Polymorphism  

Def : Ability of different types, functions, or operators to share a single interface while executing unique internal behaviors.

```python
class CreditCard:
    def process_payment(self, amount):
        return f"Charging ${amount} to Credit Card"

class Paytm:
    def process_payment(self, amount):
        return f"Redirecting ${amount} to Paytm gateway"

# A standalone function that accepts any object with a process_payment method
def complete_checkout(payment_gateway, amount):
    print(payment_gateway.process_payment(amount))

complete_checkout(CreditCard(), 100) # Output: Charging 100 to Credit Card gateway
complete_checkout(Paytm(), 50)       # Output: Redirecting 50 to Paytm gateway

```

6. Class Variable

- Also called a static variable.
- A variable defined directly inside a class body but outside any of its methods. A class variable exists in only one place and belongs to the class itself.

Q : What is its real world use ?
Ans : Class variables are used to store data that should be shared across all instances of a class.

```python
class Student:
    # Class variable (shared by all employees)
    school_name = "Bloom School" 

    def __init__(self, name):
        # Instance variable (unique to each employee)
        self.name = name 

# Accessing via class name (Recommended)
print(Student.school_name)  # Output: Bloom School

# Both instances share the same class variable
stu1 = Student("Ami")
stu2 = Student("Amy")
print(stu1.school_name)      # Output: Bloom School
print(stu1.name)            # Output: Ami
print(stu2.school_name)      # Output: Bloom School
print(stu2.name)            # Output: Amy

```

8. Property Decorators

Def - A property decorator lets you control how a variable is accessed, changed, or deleted, while still allowing users to treat it like a normal attribute.

- Think of it this way :  
    - Without a property: You access data directly.
    - With a property: Python secretly calls a method whenever you read or change the data.

Q : Why Do We Need Properties ?
- Suppose you have a student's marks.

```python
class Student:
    def __init__(self):
        self.marks = 80

s = Student()
print(s.marks)      # Output : 80
s.marks = -50       # changing marks to invalid value : -50
print(s.marks)      # Output : -50
```

Using Decorator, we allow Python to first check the validation then allow it to change the values of Marks.

```python
class Student:
    def __init__(self):
        self._marks = 80

    @property
    def marks(self):
        return self._marks

    @marks.setter
    def marks(self, value):
        if 0 <= value <= 100:
            self._marks = value
        else:
            print("Invalid Marks")

s = Student()

print(s.marks)

s.marks = 95
print(s.marks)

s.marks = -20
```

Types of Property Decorators : 
1. @property (Getter) : Used to read a value.

```python
class Student:

    def __init__(self):
        self._name = "Ami"

    @property           # @property : (Getter) - To read value from attribute
    def name(self):
        return self._name

s = Student()
print(s.name)
```

2. @name.setter (Setter) : Used to change a value.

```python
class Student:

    def __init__(self):
        self._name = "Ami"

    @property           # reading value from _name
    def name(self):
        return self._name

    @name.setter        # changing value to value from main()
    def name(self, new_name):       # method gets invoke when a new value is assigned to method.
        self._name = new_name

s = Student()

s.name = "Amy"          # setter gets invoked
print(s.name)           # Output : Amy
```

3. @name.deleter (Deleter) : Used when deleting a value.

```python
class Student:

    def __init__(self):
        self._name = "Ami"

    @property
    def name(self):
        return self._name

    @name.deleter
    def name(self):
        print("Name Deleted")
        del self._name

s = Student()
del s.name          # deleted gets invoked, Output : Name Deleted
```

## Easy Way to Remember

Suppose the property is `marks`.

| Decorator | Purpose | How You Use It | What Python Calls Behind the Scenes |
|-----------|---------|----------------|-------------------------------------|
| `@property` | Read (Get) the value | `print(s.marks)` | `s.marks()` (getter method is called automatically) |
| `@marks.setter` | Change (Set) the value | `s.marks = 90` | `marks.setter(90)` (setter method is called automatically) |
| `@marks.deleter` | Delete the value | `del s.marks` | `marks.deleter()` (deleter method is called automatically) |

> **Memory Trick:**  
> - **Getter** → Read the value (`print(s.marks)`)  
> - **Setter** → Change the value (`s.marks = 90`)  
> - **Deleter** → Delete the value (`del s.marks`)

9. Class Inheritance with isinstance() method

Q : What is isinstance()?
Ans : The isinstance() function checks whether an object belongs to a particular class or any of its parent (base) classes.

Syntax : 
```python 
isinstance(object, class_name)
```
- object → The object to check.
- class_name → The class you want to compare against.
- Returns: True or False.

Example - 
```python
class Student:
    pass

s1 = Student()

print(isinstance(s1, Student))      # Output : True
```

Using Inheritance - 
```python
class Animal:
    pass

class Dog(Animal):
    pass

d1 = Dog()

print(isinstance(d1, Dog))          # Output : True
print(isinstance(d1, Animal))       # Output : True
```

Q : Why is it used ?
- isinstance() used to check that an object is of the expected type before performing an operation.

For example - 

```python
class Student:      # Students needs to take exam
    pass

class Teacher:      # Teachers will act as Proctor
    pass

def take_exam(person):      # accepting instance of class
    if isinstance(person, Student):     # if object is of class Student, Response : True
        print("Exam Started")
    else:
        print("Only students can take the exam")

s = Student()       # instance created
t = Teacher()

# access method - take_exam to confirm if user is allowed to take example
take_exam(s)        # Student is allowed to take exam - Output : Exam Started
take_exam(t)        # Teacher are not allowed to take exam - Output : Only students can take the exam
```

10. Multiple In-Heritance

Q : What is Multiple Inheritance?
- Multiple Inheritance is a type of inheritance where one child class inherits properties and methods from two or more parent classes.

- In simple words:
    - One child class can have multiple parents.

```python
class Parent1:
    pass

class Parent2:
    pass

class Child(Parent1, Parent2):
    pass
```

```text
Parent1      Parent2
     \        /
      \      /
       \    /
        Child
```

1. Basic Multiple Inheritance

```python
class Father:
    def bike(self):
        print("Father owns a Bike")

class Mother:
    def car(self):
        print("Mother owns a Car")

class Child(Father, Mother):
    pass

c = Child()

c.bike()        # Output : Father owns a Bike
c.car()         # Output : Mother owns a Car
```
